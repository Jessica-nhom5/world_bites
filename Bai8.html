Thực hành theo yêu cầu hình ảnh bài học (Quan sát hình ảnh định dạng văn bản trong SGK).

  • Gợi ý thực hiện: Áp dụng linh hoạt các thẻ HTML định dạng văn bản như <b>, <i>, <u>, <strong>, <em> và thuộc tính mã màu CSS để hoàn thành mẫu bài tập thực hành theo yêu cầu của giáo viên.
van_dung_1.txt

🚀 VẬN DỤNG 1

Các bước sử dụng một màu cụ thể từ bức ảnh làm màu tiêu đề cho bài thơ:

  • 1. Chọn màu cụ thể: Sử dụng công cụ lấy màu (Color Picker / Eyedropper) để lấy mã màu hex (ví dụ: #14704f) mong muốn từ bức ảnh.
  • 2. Chọn ảnh nền: Chọn một bức ảnh phù hợp để làm nền cho tiêu đề (hoặc dùng khung nền màu đơn giản).
  • 3. Tạo tiêu đề trong HTML: Sử dụng các thẻ tiêu đề chuẩn như <h1>, <h2> hoặc <h3> để nhập tên bài thơ.
  • 4. Thiết lập CSS: Thêm thuộc tính background-image để chèn ảnh nền và thuộc tính color với mã màu đã chọn để định dạng màu chữ tiêu đề.
van_dung_2.txt

🚀 VẬN DỤNG 2

Tóm tắt các kiểu định dạng kiểu chữ và kích thước văn bản cơ bản trong HTML/CSS:

  • Định dạng chữ đậm: Sử dụng thẻ <strong> (nhấn mạnh ý nghĩa) hoặc thẻ <b> (chỉ làm đậm nét), hoặc thuộc tính CSS font-weight: bold;.
  • Định dạng chữ thường: Sử dụng kiểu chữ tiêu chuẩn hoặc thuộc tính CSS font-style: normal; / text-transform: lowercase;.
  • Định dạng cỡ chữ: Sử dụng thuộc tính CSS font-size (ví dụ: font-size: 16px; hoặc font-size: 1.2rem;).
